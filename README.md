### [CampusVenue — University Venue Reservations](https://github.com/senu003/campusvenue)

**Personal project · In development.** Set up a modular monolith with vertical slices, PostgreSQL, Docker, and CI. The current foundation includes ASP.NET Core Identity, sign-up, and email verification. Upcoming features include scheduling conflict checks, booking approvals, and seat reservations.

**Stack:** C# · ASP.NET Core · React · TypeScript · PostgreSQL · EF Core

### [SwiftDrop — Real-Time Parcel Tracking](https://github.com/phantomTroupeEAD/SwiftDrop/tree/main/services/tracking)

**Team project · Tracking service owner.** Built the standalone Go API for public and authenticated parcel tracking. I added ownership checks and public-data masking, then streamed parcel updates with Server-Sent Events, RabbitMQ, and Redis Pub/Sub.

**Stack:** Go · PostgreSQL · RabbitMQ · Redis · SSE
