## What I've built

### [CareerSkill](https://github.com/senu003/career-skill-platform) · ML-assisted career readiness

I built a workflow that compares CVs with job requirements, generates adaptive assessments, and uses two ML models to evaluate skill gaps and readiness. I also made CV analysis safe to retry and added request tracing to help diagnose failures.

`Python` `FastAPI` `React` `PostgreSQL` `scikit-learn`  
[Retry handling PR](https://github.com/senu003/career-skill-platform/pull/5) · [Request tracing PR](https://github.com/senu003/career-skill-platform/pull/9)

### [SwiftDrop](https://github.com/phantomTroupeEAD/SwiftDrop/tree/main/services/tracking) · Real-time tracking service

On the SwiftDrop team, I owned the Go tracking service. I built public and authenticated tracking endpoints, masked private parcel details in public responses, and streamed status updates to clients using Server-Sent Events.

`Go` `PostgreSQL` `RabbitMQ` `Redis` `SSE`  
[Tracking service design and implementation](https://github.com/phantomTroupeEAD/SwiftDrop/blob/main/services/tracking/README.md) · [Tracking PR](https://github.com/phantomTroupeEAD/SwiftDrop/pull/78)

### [CampusVenue](https://github.com/senu003/campusvenue) · University venue booking

**Personal project in development.** I set up the ASP.NET Core and React application with sign-up, email verification, and automated checks. The project uses a modular monolith with vertical slices. The roadmap covers venue availability, booking approvals, and seat reservations.

`C#` `ASP.NET Core` `React` `TypeScript` `EF Core`
